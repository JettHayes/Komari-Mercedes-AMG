## 🏎️ Design Philosophy & Overview

**Komari Mercedes-AMG** is a bespoke third-party theme crafted specifically for the open-source monitoring dashboard [Komari](https://github.com/komari-monitor/komari).

Instead of another bland grid of plain gauges and generic status cards, this theme approaches infrastructure monitoring from trackside engineering perspective:

- **AMG Telemetry Aesthetics**: Sleek dark glass panels layered over racing carbon textures, highlighted with vibrant Petronas green accents.
- **Timing Tower Grid**: Treat your distributed cloud servers and edge instances as a live racing lineup, sorted and organized by status and workload.
- **Built-in Mock Fleet Simulation**: No backend running yet? The project ships with an out-of-the-box virtual racing fleet so you can test animations, globe interactions, and layouts instantly.

> 💡 **Notice**: This repository delivers the frontend theme layer and contains no backend collector or agent binaries. Download the release package and upload it directly into your Komari admin dashboard.

## 🚀 Installation & Deployment

### Method A: Upload Theme Package (Recommended)

1. Grab the latest `.zip` release asset from the [Releases page](https://github.com/JettHayes/Komari-Mercedes-AMG/releases/latest).
2. Head over to your Komari administration panel → **Settings** → **Themes**.
3. Upload the downloaded `.zip` file and select **Komari-Mercedes-AMG** as your active theme.
4. Refresh your homepage and enjoy the pit-wall telemetry experience.

> ⚠️ **Note**: Do not use the raw *Source code (zip)* auto-generated by GitHub, as it lacks static build artifacts and cannot be loaded by Komari.

---

### Method B: Local Development & Custom Builds

If you wish to customize colors, metrics, or components:

#### 1. Prerequisites
- **Node.js** 22.0 or newer
- Package manager: `npm` / `pnpm`

#### 2. Local Testing
```bash
# 1. Install dependencies
npm install

# 2. Start local Next.js dev server
npm run dev
```
Open `http://localhost:3000` in your browser.
- When no live Komari backend is reached, the UI automatically activates the **Demo Data** fleet for hassle-free styling.
- To connect to a live remote Komari instance during development, create a `.env.local` file:
  ```env
  NEXT_PUBLIC_API_TARGET=http://YOUR_SERVER_IP:25774
  ```

#### 3. Build & Package
```bash
# Compile static theme export
npm run build
```
The static build lands in `dist/`. Archive the contents together with `komari-theme.json` and `preview.png` to create your own distribution package.

## ⚙️ Configurable Options

Administrators can set server defaults via `komari-theme.json` while visitors can also toggle their local preferences:

- 🎨 **Appearance**: Switch freely between Dark Armor and Clean Light modes.
- 🗂️ **Display Density**: Select Large Cards, Compact Grid, or Racing Table layout.
- 🌍 **Module Controls**: Toggle the 3D Globe, Region split, and Net-pace trend on or off.
- 🔒 **Guest Privacy**: Choose whether to hide server pricing, remaining value, and expiry dates from anonymous visitors.

## 🛠️ Technology Stack

- **Framework**: Next.js (App Router, Static HTML Export)
- **Languages**: TypeScript 5.x + React 19
- **Styling**: Tailwind CSS v4 + Custom glassmorphism atomic utilities
- **UI Primitives**: Radix UI + Shadcn UI
- **Visuals**: Recharts + D3-Geo projections
- **Communication**: Robust JSON-RPC 2.0 client (WebSocket & HTTP dual-mode)
